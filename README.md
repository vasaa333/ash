# Telegram Shop Bot 🤖

Современный Telegram бот для продажи цифровых товаров с полностью переработанным инлайн-интерфейсом и мощной админ-панелью.

## ✨ Основные возможности

### Для пользователей
- 🛍 **Интуитивный каталог товаров** с инлайн-кнопками
- 📍 **Пошаговый процесс покупки**: товар → город → район → вес/цена → подтверждение
- 💬 **Уведомления** на каждом шаге через callback
- ↩️ **Удобная навигация** с кнопками "Назад"
- 📊 **Счетчики** доступных товаров в каждой категории

### Для администраторов
- ⚙️ **Полная админ-панель** с инлайн-интерфейсом
- ➕ **Управление товарами**: добавление, просмотр списка
- 🌆 **Управление городами**: добавление, просмотр списка
- 🏘 **Управление районами**: пошаговое добавление с выбором города
- 📦 **Пополнение склада** в 5 шагов:
  1. Выбор товара
  2. Указание веса и цены (`100|5000` - 100г за 5000₽)
  3. Выбор города
  4. Выбор района
  5. Ввод зашифрованных данных (координаты, описание)
- 📊 **Подробная статистика** по товарам, продажам и заказам
- 🔒 **Шифрование данных товаров** (base64)

## 🚀 Быстрый старт

### Установка

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository-url>
   cd telegram-shop-bot
   ```

2. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения**
   
   Создайте файл `.env` в корне проекта:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_ID=ваш_telegram_user_id
   DATABASE=bot.db
   ```

   > **Как получить:**
   > - `BOT_TOKEN`: Создайте бота через [@BotFather](https://t.me/BotFather)
   > - `ADMIN_ID`: Узнайте свой ID через [@userinfobot](https://t.me/userinfobot)

4. **Запустите бота**
   ```bash
   python bot.py
   ```

## 📖 Руководство пользователя

### Покупка товара

1. Отправьте `/start` боту
2. Нажмите **🛍 Каталог товаров**
3. Выберите товар (показано количество доступных единиц)
4. Выберите город
5. Выберите район
6. Выберите вес и цену
7. Подтвердите покупку
8. Получите данные товара (расшифрованные автоматически)

### Использование админ-панели

1. Отправьте `/start` боту (как администратор)
2. Нажмите **⚙️ Админ-панель**

#### Добавление товара
1. **➕ Добавить товар**
2. Введите название товара

#### Добавление города
1. **➕ Добавить город**
2. Введите название города

#### Добавление района
1. **➕ Добавить район**
2. Выберите город из списка
3. Введите название района

#### Пополнение склада
1. **📦 Пополнить склад**
2. Выберите товар из списка
3. Введите вес и цену через `|` (например: `100|5000`)
4. Выберите город
5. Выберите район
6. Введите текстовые данные (координаты GPS, описание местоположения и т.д.)

Данные будут автоматически зашифрованы и сохранены в БД!

#### Просмотр статистики
**📊 Статистика** - покажет:
- Количество товаров
- Количество городов и районов
- Доступные товары на складе
- Количество проданных товаров
- Общее количество заказов

## 🗄 Структура базы данных

База данных SQLite создается автоматически при первом запуске.

### Таблицы

- **products** - Товары (id, name, created_at)
- **cities** - Города (id, name, created_at)
- **districts** - Районы (id, city_id, name, created_at)
- **inventory** - Товарные единицы (id, product_id, city_id, district_id, weight_grams, price_rub, data_encrypted, status, created_at, sold_at, buyer_id)
- **orders** - Заказы (id, user_id, inventory_id, created_at)

### Индексы для быстрого поиска
- По статусу товара
- По товару, городу, району

## 🔧 Технические детали

### Используемые технологии
- **Python 3.10+**
- **pyTelegramBotAPI** - Telegram Bot API
- **SQLite3** - База данных
- **python-dotenv** - Управление переменными окружения
- **base64** - Шифрование данных

### Особенности реализации
- Модульная архитектура с разделением логики
- Использование `user_states` и `user_data` для отслеживания состояния пользователей
- Все callback'и обрабатываются с уведомлениями (`query.answer()`)
- HTML-форматирование сообщений
- Эмодзи для улучшения UX
- Обработка ошибок и граничных случаев
- Логирование в файл и консоль

## 🔒 Безопасность

- ✅ Данные товаров шифруются перед сохранением в БД
- ✅ Проверка прав администратора на все админ-функции
- ✅ Проверка доступности товара перед продажей (race condition protected)
- ✅ .env файл не коммитится в репозиторий

## 🐛 Устранение неполадок

### Бот не отвечает
- Проверьте, что токен в `.env` правильный
- Убедитесь, что бот запущен
- Проверьте логи в `bot.log`

### Админ-панель недоступна
- Проверьте, что `ADMIN_ID` в `.env` совпадает с вашим Telegram ID
- Перезапустите бота

### Ошибка базы данных
- Удалите `bot.db` и перезапустите бота (база создастся заново)
- Если были данные, восстановите из резервной копии
